# narranexus-contracts

NarraNexus plugin contracts: manifest kinds, ports, hook specs, host events and the distribution declaration — the only import a plugin needs at type level.

Part of the `narranexus` namespace package (`import narranexus.contracts`); shipped as its own wheel so a plugin can depend on the contracts alone (plugin platform batch 6d, spec section 19.7). Versioned in lockstep with the engine.
