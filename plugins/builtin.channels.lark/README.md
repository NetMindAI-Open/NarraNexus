# Lark (`builtin.channels.lark`)

Builtin module LarkModule (IM channel: trigger + module + tools). The lark-oapi SDK installs on demand on a slim build.

A NarraNexus builtin plugin, packaged as `narranexus-plugin-channels-lark` (plugin platform batch 6b). Code: `src/narranexus_plugins/lark_module/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
