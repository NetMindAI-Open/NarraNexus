# Turn Pipeline (`builtin.turn`)

The seven-stage turn pipeline: default stage strategies and the builtin profiles.

A NarraNexus builtin plugin, packaged as `narranexus-plugin-turn` (plugin platform batch 6b). Code: `src/narranexus_plugins/turn/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
