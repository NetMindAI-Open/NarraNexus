# LLM providers (`builtin.providers`)

Provider drivers: custom anthropic/openai, NetMind, Yunwu, OpenRouter, OAuth subscriptions, system pool.

A NarraNexus builtin plugin, packaged as `narranexus-plugin-providers` (plugin platform batch 6b). Code: `src/narranexus_plugins/providers/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
