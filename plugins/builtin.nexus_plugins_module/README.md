# Nexus Plugins Module (`builtin.nexus_plugins_module`)

Agent self-extension: scaffold, test, register and observe plugins (local only).

A NarraNexus builtin plugin, packaged as `narranexus-plugin-nexus-plugins-module` (plugin platform batch 6b). Code: `src/narranexus_plugins/nexus_plugins_module/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
