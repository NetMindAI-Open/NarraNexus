# Claude Code agent loop (`builtin.frameworks.claude_code`)

Claude Agent SDK driver; SDK installed on demand on the local build.

A NarraNexus builtin plugin, packaged as `narranexus-plugin-frameworks-claude-code` (plugin platform batch 6b). Code: `src/narranexus_plugins/frameworks_claude_code/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
