# Codex agent loop (`builtin.frameworks.codex_cli`)

OpenAI Codex SDK driver; SDK installed on demand on the local build.

A NarraNexus builtin plugin, packaged as `narranexus-plugin-frameworks-codex-cli` (plugin platform batch 6b). Code: `src/narranexus_plugins/frameworks_codex_cli/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
