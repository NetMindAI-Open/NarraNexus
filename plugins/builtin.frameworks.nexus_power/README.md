# NexusPower agent loop (`builtin.frameworks.nexus_power`)

The home-grown agent loop; always available. Declares its strategy seats as extension points.

A NarraNexus builtin plugin, packaged as `narranexus-plugin-frameworks-nexus-power` (plugin platform batch 6b). Code: `src/narranexus_plugins/frameworks_nexus_power/`; manifest: `narranexus-plugin.json` (mirrored by `narranexus.kernel.plugins.builtins` until distributions generate it). Depends on the engine (`narranexus`) only.
