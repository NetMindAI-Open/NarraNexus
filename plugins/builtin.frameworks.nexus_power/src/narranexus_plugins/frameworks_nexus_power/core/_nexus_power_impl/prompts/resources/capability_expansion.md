# Expandable capabilities

The platform offers additional capabilities beyond the tools currently
in scope. Each line below is one capability: its key and what it does.

To use one, call `expand_capability` with its key. Expanding loads that
capability's full instructions and tools into this turn. Expansion
costs context — expand what the task needs, when it needs it, rather
than expanding everything up front. Expanding the same key twice is
harmless. What you expand lasts for the rest of this turn.
