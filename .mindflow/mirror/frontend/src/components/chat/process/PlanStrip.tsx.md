# PlanStrip.tsx — 钉在输入框上方的实时计划

## 为什么它没跟着搬进文稿

2026-08-31 拆框时，相位去了文稿开头，唯独 plan 留在原位。理由是它回答的是
**「现在到哪了」**——折进文档流就会跟着滚上去，而长回合恰恰是它最有用的时候。
退役的 `ProcessPanel` 把它钉在滚动区之外，也是同一个理由。

## 为什么仍然去框

**钉住是位置，不是语域。** 现在它坐在页面底色上，只有一条 `border-t` 细线做
分隔（design_system §2.6 允许的那条），没有填充、没有圆角、没有阴影——不再
读作「另一个文档」。

## 刻意不做的事

- **无 plan 时整体不渲染**（返回 null）。多数回合没有 plan，留一条常驻的
  无解释横线在输入框上方比没有更糟。测试钉住这一条。
- **不画过程事件**。同 [[RunPhases]]，流里已有。
- **不做折叠态迷你进度条**。退役面板有 `process-plan-mini`，那是折叠整个
  盒子时的替身；没有盒子就没有折叠，替身也就没有存在理由。

## Gotcha

plan 是 **replace-on-write 全量快照**：取 `events` 里最后一条，不要累加——
按追加渲染会把每一版计划都堆在屏幕上。测试里有一条钉住。
