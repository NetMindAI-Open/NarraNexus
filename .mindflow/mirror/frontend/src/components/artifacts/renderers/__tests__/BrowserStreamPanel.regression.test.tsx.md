# 浏览器连接与输入回归

集中保护跨异步边界的行为：首帧鉴权、断线重连、切换智能体后拒收旧回调、图片解码顺序、
多窗口控制权，以及按实际面板尺寸请求远程 viewport。连接替身允许确定性制造真实网络中
难稳定复现的竞态。输入测试覆盖中文组合输入、粘贴、触摸滚动和移出画面的鼠标释放，
避免只验证普通 ASCII 点击而遗漏接管登录时的核心路径。
