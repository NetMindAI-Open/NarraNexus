# 浏览器标签栏

展示所有页面与弹窗，以标题和网址区分，标明 Agent 活动页。选中页面只改变本连接的观看
目标；跟随按钮恢复 Agent 页面跟随。关闭按钮仅在接管时可用，避免旁观误关 Agent 页面。
横向滚动和固定宽度保证窄面板不被长标题撑开；键盘方向键、Home/End 切换标签。
次级文本使用现有 nm-ink70，亮暗主题继承同一语义色，不引入未定义的颜色 token。

新增加号与地址栏：人工接管后可新建空白标签，自动聚焦网址输入；省略协议补 HTTPS，
只允许 HTTP(S)，支持回车或箭头提交、Escape 取消、输入法回车不误提交。旁观可复制
当前网址但不能导航。编辑时保留草稿，交还时恢复实际网址。命令等待回执时禁用重复操作，
失败后恢复可编辑状态；控件沿用 NM TextInput/IconButton 和十种语言文案。
切页、接管与容器缩窄时滚动整个选中标签（包含关闭按钮），不能只滚动标题按钮，
否则窄面板会把关闭按钮留在可视区域以外。
