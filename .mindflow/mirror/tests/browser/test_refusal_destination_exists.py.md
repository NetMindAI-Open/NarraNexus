# 拒绝/请求所指的目的地必须真实存在

源于一次真实报告（2026-09-22）：agent 正确地说"去 设置 → 浏览器 安装"，而设置里根本没有浏览器
分区——从用户角度看与 agent 胡编无法区分。两侧各自的单测都通过，坏的是两者之间的链接，所以
这里断言的是链接本身：

1. **运行时安装拒绝**指向两个设置宿主（`/app/settings` 页与设置弹窗，分别注册）里都真实存在、且
   确有安装按钮、且走带鉴权客户端的入口；三种拒绝（安装 / 重装 / 等待）都带 `where`；agent 提示词
   里写的 "Settings → X" 必须是真实分区。
2. **登录 / 验证请求的通知**挂在 app shell（`<BrowserNotices />`），而不是只在浏览器面板里：agent 是
   在聊天里说"去完成登录"的，面板未必打开。

2026-10-08（PR #410 review）：原第二部分钉的是"独立能力审批"提示的挂载与内容；审批子系统已整体
删除，改为钉登录通知的挂载。
