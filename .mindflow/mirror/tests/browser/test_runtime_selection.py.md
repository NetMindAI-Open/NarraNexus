# 浏览器选择回归

覆盖明确选择、跨服务可见、默认不安装或自动选择、无效配置拒绝、系统浏览器不可用
时不偷偷回退，以及云端禁止选择主机浏览器。平台路径用注入的文件与系统名验证，
不是 Windows/Linux 的物理运行验收。启动集成验证正式 Chrome 保持无头内嵌模式、
使用独立 profile，修改选择不能替换现有会话。

增加模式的跨进程持久化、私有文件、非法配置、原子写入失败恢复及云端固定无头测试。
服务集成覆盖模式只作用于新会话、使用同一 profile、已存在会话不受配置损坏影响，
新启动配置损坏返回结构化错误。API 验证身份、窄枚举、失败码及明确保存修复配置。
