# 多页面协议与控制

验证一个浏览器连接中各页面的帧、确认和断开相互独立。用户旁观切页不能改变 Agent
目标；接管切页先释放旧页面按键，迟到输入不得进入新页，Agent 切页继续等待人工交还。

真实 ASGI 两个观看连接验证独立选中页、共享活动页、接管广播、页面错误和迟到输入。
真实 Chrome 的发现、持续画面和页面关闭由 test_live_browser_e2e 补充。
并发测试要求首次截图完成后才下发 resize，防止 Chrome 内部截图恢复逻辑覆盖面板尺寸。
静态页回归要求尺寸变化后立即有新帧；重复尺寸、停止观看后调整均不额外补帧。
人工新建/导航覆盖控制权、旧页保留、按键释放、非网页地址拒绝、迟到导航拒绝、URL
审计脱敏、Agent 等待交还。真实 ASGI 两连接验证旁观拒绝与成功/失败回执。
