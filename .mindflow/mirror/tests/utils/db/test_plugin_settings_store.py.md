# 插件设置的数据库存储

加密落库、跨实例读回，以及同步桥（无运行中事件循环时调用 `_run()`）每次调用自建并关闭私有 loop、
不泄漏线程、不破坏本线程的 asyncio 状态。

2026-10-08（PR #410 第二轮 review I1）：线程泄漏断言改为比较**线程身份**（循环期间新建且之后仍存活
的线程），不再比较全进程 `active_count()`。后者也会因无关的早先线程在循环中退出而变化（例如测试关闭
后仍在收尾的 aiosqlite 连接线程），曾在 CI 上随测试文件增删而误报。已用"每次调用留一个存活线程"的
变异验证新断言能准确报出泄漏的线程。
