# bm25.py — BM25 原语的公共门面(纯再导出)

为什么存在(PR #361 review M2):唯一的 BM25 实现住在
`_memory_impl/retrieval.py`(memory 召回是初代消费者),但它早已长出域外
消费者——narrative 路由拿它排序且审计重放**逐位**断言分数复现、
job_repository 拿它排 job。域外 import 直打私有路径时,重构 memory 的人
收不到"这是跨域契约"的信号——改个签名就静默打断 narrative 的可重放保证。
本模块就是那个信号:**域外一律从这里 import**;这里的四个名字
(`tokenize/bm25_rank/bm25_explain/bm25_snippet`)的签名变更 = 契约变更,
需要同时过 `tests/narrative/test_routing_audit.py` 的逐位重放。

刻意不做的:不搬实现(实现和 memory 自己的消费者留在原地);
`_bm25_term_contributions` 不导出(它是 rank/explain 共享算术的内部收敛点,
不是外部契约)。既有的 `MemoryRepository` 跨域引用
(social_network_repository)是另一个问题,不属于本门面。
