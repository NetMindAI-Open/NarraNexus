# 浏览器来源选择

本地运行方式通过独立 runtime-mode.json 保存，仅接受 headed/headless。未选择时仍
为无头；云端固定无头且拒绝写入。模式与来源文件共用私有原子写入方法，但各自保存，
避免并发更新覆盖另一项设置。读取损坏配置明确报错；模式变化不改变 profile 路径。

用户可以明确选择已安装的正式版 Chrome，继续通过内嵌画布操作。只查找各系统的
已知稳定版安装位置，不搜索任意可执行文件，不打开或导入个人浏览器 profile。
默认仍为原有托管浏览器；没有选择不自动使用系统浏览器，也不下载任何内容。

来源以仅含 source 的 JSON 原子保存到统一浏览器目录，API 和 MCP 每次读取新值；
Finder 启动的桌面版与开发版不依赖 shell 环境变量传递。不存在时用默认选择，损坏
或未知字段则报错，不能悄悄改用另一个浏览器。选择系统浏览器前验证可执行文件。
云端固定使用托管浏览器，禁止用户改变服务器浏览器来源。

本组件不停止浏览器；新会话采用新选择，已存在的会话继续运行。不同来源使用独立
的智能体 profile，避免系统 Chrome 比托管版本旧时降级读取数据。
